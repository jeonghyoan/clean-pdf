# clean-pdf

Ad-free local PDF viewer and toolset (PWA). Everything runs in your browser—no ads, no sign-up, no uploads.

- Live: https://jeonghyoan.github.io/clean-pdf/

## Features

- **Viewer**: Continuous/single page, ToC, thumbnails, text search, zoom, rotation, dark mode, offline support.
- **Convert**: Images ↔ PDF, PDF → text (`.txt`), merge, split, reorder/delete pages.
- **Annotate & Manage**: Sticky notes, draw/sign, watermark, page numbers, compress, password unlock.
- **Local Storage**: Up to 5 recent files (≤30 MB each) and sticky notes saved in IndexedDB.
