# clean-pdf

Ad-free local PDF viewer and toolset (PWA). Everything runs in your browser—no ads, no sign-up, no uploads.

- Live: https://jeonghyoan.github.io/clean-pdf/

## Features

- **Viewer**: Continuous or single-page mode, table of contents, thumbnails, text search with highlights, zoom/pinch, rotation, dark mode, and offline support.
- **Convert & Organize**: Images to PDF (unlimited), PDF to PNG/ZIP, PDF to `.txt`, merge PDFs, split/extract pages, reorder or delete pages.
- **Annotate & Manage**: Sticky notes (saved per file and exportable into PDF), draw/sign, watermark (including Korean), page numbers, compression, and password unlock.
- **Local Storage**: Up to 5 recent files (≤30 MB each) and sticky notes are stored locally in IndexedDB.

## Install (PWA)

1. Open the live URL in Chrome (or Safari on iOS).
2. Choose **Install app** (or **Add to Home screen**) from the browser menu.
3. Launch from your home screen—it runs standalone and works offline.

## Privacy

Files, notes, and search terms never leave your device. Only UI preferences and local document data are stored in your browser.
